# Customer Personality Analysis – Data Cleaning (Excel)

## 📌 Project Overview
This project focuses on cleaning and preparing the **Customer Personality Analysis dataset** using Microsoft Excel.  
The goal was to transform raw, inconsistent data into a structured format suitable for analysis and visualization.

---

## 🛠️ Tools Used
- Microsoft Excel (Excel Online)
- Basic Data Cleaning Techniques

---

## ✅ Data Cleaning Steps Performed
- Split merged data into proper columns using **Text to Columns**.
- Fixed column alignment issues and ensured each value belongs to its respective field.
- Standardized the **Dt_Customer** column by converting mixed text/date formats into a consistent date format.
- Adjusted column widths to resolve display errors (######).
- Verified and corrected data types (e.g., numeric fields, date fields).
- Ensured consistent formatting for better sorting and filtering.
